# Бот-колода: приветствие → мини-апп из 7 слайдов → заявка

Повторяет формат бота gconf: одно приветственное сообщение с двумя кнопками, за кнопкой —
Telegram Mini App с колодой слайдов (прогресс-бар, нумерованные карточки, чёрная кнопка «дальше»
с подсказкой справа, вечная строка «или сразу: …» внизу), заявки и вопросы падают куратору в чат.

```
bot/
├── content.json      ← весь текст бота и слайдов. Меняется только он
├── webapp/index.html ← мини-апп (статика, кладётся на https-хостинг)
├── bot.mjs           ← сам бот, Node 18+, без зависимостей
└── .env.example
```

## 1. Контент

Всё, что видит пользователь, лежит в `content.json`. Код трогать не нужно, слайдов может быть
любое количество — прогресс-бар и счётчик считаются сами.

| Поле | Что это |
|---|---|
| `brand.name` / `botUsername` | заголовок и подпись внизу мини-аппа |
| `brand.theme` | вся визуальная система: цвета, скругления, размер и регистр заголовка |
| `start.text` | первое сообщение после `/start` |
| `start.buttons` | подписи двух кнопок: мини-апп и «задать вопрос» |
| `cta` | строка «или сразу: …», текст сообщения с заявкой и ссылка на форму |
| `slides[]` | сами слайды |

Слайд:

```jsonc
{
  "id": "intro",              // произвольный ключ для статистики
  "kicker": "о наборе",       // строка «01 // О НАБОРЕ»
  "nextHint": "запросы",      // серая подсказка справа в кнопке «дальше»
  "badge": "НАБОР ОТКРЫТ",    // плашка акцентом (необязательно)
  "title": "фуд-споты\nна ==пикнике==",  // ==текст== = подсветка, \n = перенос
  "lead": "абзац под заголовком",
  "meta": [{ "label": "СТАРТ", "value": "26.06" }],   // до трёх колонок
  "sectionTitle": "ЧТО ВЫ ПОЛУЧАЕТЕ",
  "list": {
    "style": "rows",          // rows — строки, cards — карточки, steps — шаги с линией
    "items": [{ "title": "заголовок", "quote": "пояснение или цитата" }]
  },
  "note": "сноска с акцентной чертой"
}
```

Бот перечитывает `content.json` на лету — правки видны без перезапуска.

## 1.1. Визуальный стиль

`brand.theme` — единственное место, где живёт оформление. Любой ключ превращается в css-переменную
(`titleSize` → `--title-size`), так что тему можно переставить, не трогая вёрстку:

| Ключ | Что меняет | Пример другой подачи |
|---|---|---|
| `accent` | цвет подсветки, плашек, номеров | `#c9f24a` → `#ff5c39` |
| `ink` / `paper` | текст и фон | инверсия: `ink: "#ffffff"`, `paper: "#0f0f0f"` |
| `muted` / `line` | второстепенный текст и линейки | |
| `radius` | скругление карточек и кнопок | `14px` → `0px` (жёсткая сетка) или `28px` |
| `titleSize` | размер заголовка | `9vw` → `12vw` (плакатная подача) |
| `titleCase` | регистр | `lowercase` → `none` или `uppercase` |
| `titleWeight` | насыщенность | `800` → `400` (спокойная типографика) |
| `display` | отдельный шрифт заголовков | любой css-стек |

## 2. Мини-апп на https

Мини-апп открывается только по https. Самый короткий путь — GitHub Pages этого репозитория:
Settings → Pages → Source: `Deploy from a branch`, ветка с этим кодом, папка `/ (root)`.
Адрес получится вида `https://<логин>.github.io/<репозиторий>/bot/webapp/`.

Локально: `npm run webapp` в папке `bot` и открыть `http://localhost:8000/bot/webapp/`
(через `file://` не заработает — мини-апп читает `content.json` запросом).

## 3. Бот

1. `@BotFather` → `/newbot` → токен.
2. Там же `/setmenubutton` — если нужна кнопка мини-аппа в меню чата.
3. Свой `chat_id` для заявок — у `@userinfobot`.

```bash
cp bot/.env.example bot/.env   # заполнить
BOT_TOKEN=... WEBAPP_URL=https://.../bot/webapp/ ADMIN_CHAT_ID=... node bot/bot.mjs
```

Бот работает на long polling: не нужен ни вебхук, ни белый ip. Подойдёт любой сервер,
где процесс живёт постоянно (Railway, Render, VPS, домашний мини-сервер).

## Что делает бот

- `/start` — присылает приветствие, ставит клавиатуру с двумя кнопками и дублирует их под сообщением.
- **Кнопка мини-аппа** — открывает колоду. На последнем слайде и по строке «или сразу: …» — заявка.
- **Заявка** — пользователю уходит сообщение с ссылкой на форму, куратору — уведомление
  с именем, юзернеймом и числом просмотренных слайдов.
- **Кнопка «задать вопрос»** и любое свободное сообщение — уходят куратору. Куратор отвечает
  реплаем на это уведомление, ответ приходит пользователю в бот.
- `/stats` (только в чате куратора) — сколько людей, сколько дошли до конца колоды, заявки, вопросы.

Состояние (кто где остановился, заявки, связка «сообщение куратора → пользователь») лежит в
`bot/data/state.json` — обычный json, папка не коммитится.

## Ограничение, о котором легко споткнуться

Мини-апп умеет отправлять данные обратно в бота (`sendData`) только если открыт кнопкой
**обычной клавиатуры** — той, что появляется рядом с полем ввода. Если открыть его инлайн-кнопкой
под сообщением, заявка не долетит до бота, поэтому в этом случае кнопка ведёт напрямую на
`cta.url`. Обе клавиатуры бот ставит сразу, так что путь всегда рабочий.
