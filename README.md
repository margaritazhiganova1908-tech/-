# Пикник Афиши 2027 · План автоматизации

Прототип внутреннего веб-приложения (личный кабинет резидента) в одном файле — `index.html`.
Открывается двойным кликом в любом браузере, без сборки, сервера и внешних запросов.

## Оформление

Палитра и типографика — по гайду `picnic24_guide.pdf`: небесно-голубой фон, кислотный лайм,
неоновый розовый, красный для запретов и штрафов; крупные контурные заголовки строчными буквами.
Фирменный шрифт — **Pavliuchenko** (`--font-display`), с фолбэком на Arial Black / Impact,
если шрифт не установлен в системе. Цвета вынесены в CSS-переменные `:root`.
Кнопка «Тема» в шапке переключает фирменную светлую тему и тёмную (выбор запоминается в браузере).

## Разделы

1. **Кабинет** — карточка резидента (Underdog, куратор Наталья Арсентьева, ФК1 · блок B · точка 12)
   и 10 этапов: Заявка → Одобрение заявки → Загрузка данных резидента → Оплата → Тех Хостинг →
   Монтаж → Демонтаж → Загрузка данных по выручке → Закрывающие документы → Обратная связь.
   - «Загрузка данных резидента» раскрывает список с кнопками «Загрузить»: списки на аккредитацию,
     меню, информация для промо, реквизиты.
   - «Тех Хостинг» — памятка резидента фудкорта, разложенная по 7 сворачиваемым разделам:
     главное, безопасность, продажи, монтаж, своя застройка (документы для МЧС), на фестивале,
     демонтаж. Внутри — плашки с ключевыми цифрами, блоки «Запрещено», штрафы и чек-листы.
2. **Выбор места** — схемы фуд-кортов:
   - Москва ФК1: 4 блока (A, B, C, D) по 9 корнеров, центральный корнер каждого блока — тех. зона,
     в центре «Навигация» со столиками. Цены: A — 200 000 ₽, B — 180 000 ₽, C и D — 150 000 ₽.
   - Москва ФК2 (вторая сцена): планировка «Г», 8 корнеров 4,5×3 по 180 000 ₽, поле «Партнёр
     фуд-корта», на схеме только столики (без круга навигации).
   - ФК3 — фуд-корт Купер (сервис доставки): 5 корнеров 4,5×3, кнопка «Онбординг на платформу
     Купер — загрузка документов».
   - Питер ФК1 (2 блока по 9 корнеров) и линия из 12 фудтраков.
   Ховер — стоимость и статус, клик — карточка и бронирование. Справа: статистика, фильтры по
   статусу и площади, список корнеров.
3. **Аналитика** — вкладки городов, KPI, графики по блокам и площадям, блок «Департамент торговли»
   («Данные собраны на 18%», кнопка «Отправить данные для презентации»), задачи с чекбоксами,
   карточки локаций.

## Логика

Все данные лежат в объектах `CELLS`, `STAGES`, `TODOS` в начале скрипта.
Бронирование точки, отметка задачи или загрузка документа мгновенно пересчитывают
прогресс, статистику и графики без перезагрузки страницы.

Для продакшена структура данных переносится 1:1 в API (Node/Django/Laravel) и БД (PostgreSQL),
интерфейс — в React/Vue + Tailwind.
