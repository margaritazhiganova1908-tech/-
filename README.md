# План автоматизации · Фестиваль Underdog

Прототип внутреннего веб-приложения (личный кабинет арендатора) в одном файле — `index.html`.
Открывается двойным кликом в любом браузере, без сборки, сервера и внешних запросов.

## Разделы

1. **Кабинет** — карточка участника (Underdog, куратор Наталья Арсентьева, этап 2 из 5, ФК1 · точка 12),
   этапы «Заявка / Вход / Коммерция / Подготовка / Монтаж» с чек-листами, уведомления
   («Счёт не оплачен — 2 раб. дня»), кнопки «Платёжка», «Консультация», «Открыть счёт»,
   «Сменить площадь», сводка по счёту (смета, оплата, даты монтажа и демонтажа).
2. **Выбор места** — схемы фуд-кортов Москвы и Санкт-Петербурга:
   - Москва ФК1: 4 блока (A, B, C, D) по 9 корнеров, центральный корнер каждого блока — тех. зона,
     в центре «Навигация» со столиками для гостей. Цены: A — 200 000 ₽, B — 180 000 ₽, C и D — 150 000 ₽.
   - Москва ФК2 (вторая сцена): планировка буквой «Г», 8 корнеров 4,5×3, 180 000 ₽.
   - Питер ФК1 (2 блока по 9 корнеров) и линия из 12 фудтраков.
   При наведении на корнер — стоимость и статус, при клике — карточка и бронирование.
   Справа: статистика (доступно / продано / остаток), фильтры по статусу и площади, список корнеров.
3. **Аналитика** — вкладки городов, KPI (продано, бронь, доступно, дедлайн), горизонтальные графики
   по блокам и площадям, задачи департамента торговли с чекбоксами, карточки локаций.

## Логика

Все данные лежат в объектах `CELLS`, `STAGES`, `TODOS` в начале скрипта.
Бронирование точки, отметка задачи или загрузка документа мгновенно пересчитывают
прогресс, статистику и графики без перезагрузки страницы.

Для продакшена структура данных переносится 1:1 в API (Node/Django/Laravel) и БД (PostgreSQL),
интерфейс — в React/Vue + Tailwind.
