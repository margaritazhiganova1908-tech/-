# Карта фудкортов · бронирование мест

Публичная страница для резидентов: схемы фудкортов Москвы и Петербурга, цены и бронирование.

## Как это работает

1. Резидент открывает ссылку из рассылки, выбирает место, вводит название бренда и e-mail.
2. Бронь записывается в Google Таблицу. Менеджеру приходит письмо «Забронировано место»,
   резиденту — подтверждение.
3. Занятые места на карте сразу недоступны для брони у всех. Карта обновляется каждые 30 секунд;
   если два человека нажали одновременно, второй увидит «место только что забронировали».
4. Менеджер снимает бронь, если сделка не состоялась:
   - на карте: адрес карты + `#admin`, ввести ключ менеджера → поиск по бренду, e-mail, месту
     или номеру → «Снять бронь»;
   - или прямо в таблице: в колонке «Статус» заменить «активна» на «снята».

Пока сервер не подключён, страница работает в демо-режиме: брони видны только в том браузере,
где их сделали, письма не уходят.

## Подключение (один раз, ~10 минут)

### 1. Сервер броней — Google Apps Script

1. Создайте новую Google Таблицу (например, «Брони фудкортов 2027»).
2. В таблице: **Расширения → Apps Script**. Удалите всё в `Code.gs` и вставьте содержимое
   файла [`apps-script/Code.gs`](apps-script/Code.gs). Сохраните.
3. В редакторе выберите функцию `setup` и нажмите **Выполнить**. Google попросит доступ к таблице
   и почте — разрешите. Появятся листы «Брони» и «Заявки», а на почту придёт ключ менеджера.
4. **Развертывание → Новое развертывание → Тип: Веб-приложение**.
   - Выполнять как: **Я**
   - У кого есть доступ: **Все**
   Нажмите «Развернуть» и скопируйте адрес вида `https://script.google.com/macros/s/…/exec`.
5. Вставьте этот адрес в `index.html` в строку `var API_URL = '';` (между кавычками).

Адрес почты для уведомлений задан в начале `Code.gs` (`MANAGER_EMAIL`).
После правки `Code.gs` нужно сделать **Развертывание → Управление развертываниями → Изменить →
Новая версия**, иначе изменения не вступят в силу.

### 2. Публичная ссылка — GitHub Pages

Репозиторий → **Settings → Pages → Build and deployment → Deploy from a branch** →
ветка `claude/brave-cray-8amkwf`, папка `/ (root)` → Save.

Через 1–2 минуты карта откроется у всех по адресу:
`https://margaritazhiganova1908-tech.github.io/-/foodcourts/`

## Ограничения

- Ссылку может открыть любой, у кого она есть, и забронировать место. Ложные брони менеджер
  снимает вручную.
- Почта отправляется с аккаунта Google, где развернут скрипт; лимит бесплатного Gmail —
  около 100 писем в день.
- Код на билете декоративный, по нему ничего не считывается.
